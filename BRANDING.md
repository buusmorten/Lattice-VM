# Lattice VM

Lattice VM is an independent open-source fork of UTM. It is not affiliated with
or endorsed by the UTM project.

## Brand

- Product name: Lattice VM
- Visual idea: connected virtual-machine layers forming a luminous portal
- Primary colors: midnight navy, electric cyan, violet blue, and coral
- Master icon: `Branding/LatticeVM-AppIcon.png`
- Application bundle name: `Lattice VM.app`
- Xcode project: `LatticeVM.xcodeproj`
- Default bundle identifier namespace: `org.latticevm`

The Lattice VM name and icon are original fork branding. Upstream copyright and
license notices remain applicable to the underlying UTM code.

Internal `UTM` type names, scripts, schemes, package extensions, and some
intermediate artifact names are retained where changing them would break source
or virtual-machine compatibility. They are implementation details, not product
branding.
